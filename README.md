# Arcade Retro - Minijuegos Clásicos

## 📋 Descripción del Proyecto

Este proyecto es una plataforma web interactiva de minijuegos clásicos desarrollada en JavaScript vanilla, HTML y CSS. Su objetivo principal es ofrecer una colección de juegos retro centralizados en una misma interfaz, donde el usuario puede navegar a través del menú principal, seleccionar el juego que prefiera y ver una tarjeta informativa con la descripción y detalles antes de comenzar a jugar.

---

## 🕹️ Juegos Incluidos

1. **Adivina el Número**  
   Juego de deducción donde el usuario debe adivinar un número secreto generado aleatoriamente. Incluye pistas dinámicas de "mayor" o "menor" tras cada intento y un sistema de potenciadores para facilitar la búsqueda.

2. **Piedra, Papel o Tijera**  
   El clásico juego de estrategia contra la máquina. Cuenta con marcador en tiempo real y potenciadores especiales que permiten modificar las reglas estándar de la partida.

3. **Ahorca-2**  
   El tradicional juego del ahorcado donde debes descubrir la palabra oculta letra por letra antes de agotar tus vidas. Incorpora potenciadores para revelar pistas o proteger tus vidas erróneas.

4. **Snake**  
   El emblemático juego de la serpiente donde debes moverte por la pantalla comiendo manzanas para crecer. Incluye potenciadores especiales en el mapa que otorgan habilidades temporales a la serpiente.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica de la interfaz y del menú principal.
* **CSS3:** Estilos personalizados, animaciones, transiciones dinámicas y control de capas.
* **JavaScript (ES6):** Manipulación del DOM, control de eventos, gestión de tarjetas y lógica completa de cada minijuego y sus potenciadores.

---

## 📌 Nota sobre la Visualización

Este proyecto está diseñado con dimensiones fijas para preservar la estética y distribución exacta de la interfaz. 

> ⚠️ **Recomendación de visualización:** Para disfrutar de la mejor experiencia visual y asegurar que todos los elementos se muestren alineados correctamente, es posible que en algunas pantallas o resoluciones sea necesario **ajustar el zoom del navegador (Zoom out / alejar)**.
